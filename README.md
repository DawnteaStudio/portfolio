# Dawntea Studio | 박세원

[포트폴리오 열기](https://dawnteastudio.github.io/portfolio/)

AI 활용 개발자 박세원의 포트폴리오입니다. 우클링에서 Codex를 초안 작성, 구현, 검증 작업에 활용하며 요구사항과 완료 기준을 정하고, 제안의 반영 여부와 변경 범위를 판단한 사례를 소개합니다.

3인 팀이 관리할 공통 용어표로 범위를 줄인 결정과 컬럼 검토 방식을 바꾼 기록을 공개했습니다. API 계약에서는 잘못된 정렬 조건의 검사 실패와 수정 후 통과를 확인한 사례를 담았습니다. 백엔드 개발과 공식 Instagram 운영, TIL Studio, C++ IRC 서버, C 기반 셸과 CJ올리브네트웍스 인턴 경험도 소개합니다.
